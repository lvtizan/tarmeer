## 用户追加：日期按业务含义校验

动态 schema 增加规则，前端与后端一致按迪拜日期判断：年份/日期下限 1900；成立年不能超过当前年；实际访谈、项目完工日期不能晚于今天；执照有效期允许已过期，最多未来 30 年；最早开工允许过去日期，最多未来 5 年。严格校验公历日期与闰年。已填答案不改写；仅给 V7 schema/快照增加约束元数据，备份和事务验证保护旧数据；legacy 不修改。

## 用户追加：全部问卷输入内容校验

范围先按当前访谈问卷全部步骤处理，已异步询问是否另含全站其他表单；未收到范围答复，当前按访谈问卷执行。按 schema 字段含义分类：阿联酋联系方式（TDRA 手机及固定号段）、姓名/公司、地址、可纯数字的执照标识、地图与网站链接、邮箱、人数/金额/面积、日期及枚举/附件。可选项空白允许；填写后必须合法。支持 Unicode 正常语言内容及号码常用格式，禁止静默删除或改写答案。前端提供约束与定位错误，服务端同样执行；保存不完整草稿仍允许空缺必填项。三条并行任务：服务端策略/迁移、前端体验/校验、独立规格安全审查。

号码来源：TDRA `https://tdra.gov.ae/en/consumer-tool-hub/topics/porting-numbers`；2026-10-07 核查。

## 用户追加：操作后自动保存与崩溃恢复

每次输入先同步写本机恢复缓存，失焦和选择/重复行/附件操作立即排队保存，连续输入短暂合并。按国家、记录和 schema 版本隔离缓存；只恢复修改的合法字段键，保留未通过校验的原始内容。界面区分服务器已保存与本机待同步。自动保存仅 PATCH 修改字段，避免其他标签页未修改字段被旧快照覆盖；附件删除通过服务端锁内删除增量处理，并发上传的新文件保留。提交后的编辑保持显式重新提交流程。用户已要求完成后自动提交、推送；先测试与三轮清白，再发布。
