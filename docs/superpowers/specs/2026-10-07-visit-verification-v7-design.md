# 访谈记录 V7 升级设计（已获授权并实现）

## 范围
以 Tarmeer_Verification_EN_V7.html 为字段及交互参考，同时升级外勤填写页和后台访谈详情。保留现有列表、筛选、公司绑定、权限及国家隔离。

## 六步填写
公司信息、业务类型、团队与能力、产能与项目、现场核验、复核提交。包含联系人、工种与人数、自定义工种、可用人力、设施、案例、附件、核验结论。草稿及提交继续保存到后端；参考网页的离线 IndexedDB 不作为唯一存储。公司自述与核验结果分开，不自动赋予 A/B/C 等级。

## 数据与兼容
问卷定义继续由 survey_schema 及 GET /api/field/survey-schema 提供，禁止前端硬编码字段标签及选项。保存记录所用 schema 版本或快照，旧记录按旧定义读取，新记录按 V7 读取。旧字段和记录不删除，未经确认不将历史答案推断成核验结果。迁移前备份数据库中的 schema 和受影响记录。同步公司字段须核对所有引用点及权限。

## 国家
V7 的 AED 和阿联酋地区配置限定 AE；VN/SA 保持各自国家配置，不泄漏 AE 选项和公司。所有查询及写入携带和验证国家归属。

## 响应式与错误处理
PC 左侧步骤导航、双列表单；手机横向步骤导航、单列表单、底部操作栏及安全区。复杂工种、人力、项目以卡片展示，避免横向溢出。保留草稿、必填校验、附件上传、复核与提交；加载失败显式提示并允许重试。

## 验收
