# 找专家 + 认证体系 设计文档

> 2026-06-10 确认。AE / VN 双国家同步上线，全程遵守 AGENTS.md「国家数据隔离规则」。

## 业务需求

1. 双业务线：**找公司**（现有装企）+ **找专家**（新）——专家 = 持营业执照的个人专业人士（木工/设计师/泥水工等）
2. 专家在个人中心上传资格证/营业执照；个人主页**简历式**展示
3. **电话点击才显示**（装企 + 专家都要）：点击计数 = 真实需求统计
4. 主页留言汇总到各自个人中心（装企后台 + 专家中心都新增收件箱）
5. 后台列表加**认证开关**：销售线下收 ¥1000 → 手动开通「普通认证」徽章；与 VIP（签约）徽章**并存**，认证不分级
6. **所有分类/导航数据后台可配置，禁止硬编码**

## 数据模型

| 内容 | 方案 |
|------|------|
| 专家账号 | `users.role='expert'` + 新表 `expert_profiles`：头像、姓名、服务分类(多选,JSON)、出生年、从业年限、城市、简介、技能标签(JSON)、从业经历(JSON 时间线)、证书图(JSON)、营业执照、slug、status(pending/approved)、`country`(注册手机号前缀判定)、`is_certified`、`is_signed` |
| 装企认证 | `company_profiles.is_certified` + `uae_companies.is_certified`（与 `is_signed` 并存） |
| 服务分类 | **复用** `service_categories` 两级体系（后台「类型与服务」管理），专家注册多选 |
| 空间类型 | 从 Navbar 硬编码迁出 → 后台可配置（system_config 或独立表，双语+国家维度） |
| 项目作品 | **复用** `projects` 体系：加 `expert_profile_id` 列（与 company_profile_id 二选一），审核/详情页/上下架全复用 |
| 留言 | **复用** `design_inquiries`：加 `expert_id` 列。装企留言=现有询盘；专家主页留言写同表。admin 线索统一可见，国家归桶（手机号前缀）现成 |
| 电话点击 | 新表 `phone_reveals`(target_type: company/expert, target_id, country, viewer_ip, created_at)；同 IP 同目标当天去重防刷 |

## 前台

- 导航改造为**「找公司」+「找专家」**双入口（后台配置数据源）：
  - 找公司 → 空间类型（后台可配，双国家各自列表）→ 公司列表筛选
  - 找专家 → 服务类型（service_categories 两级）→ 专家列表筛选
  - 现有 `/services/*` SEO 落地页保留；专家量起来前，服务落地页同时展示该服务的专家+公司
- 专家列表 `/experts`：职业/城市筛选，卡片含头像/姓名/服务/从业年限/认证+VIP 徽章
- 专家主页 `/experts/[slug]` 简历式：名片头(头像/姓名/徽章/年龄·从业年限·城市) → 简介 → 从业经历时间线 → 技能 → 证书展示(执照只显示"已核验") → 项目作品(复用项目详情交互) → 电话(点击显示) → 留言表单
- **电话点击显隐组件**（装企详情 + 专家主页共用）：默认遮罩 `09x···`，点击 → POST /phone-reveals（后端返回完整号码并计数）→ 显示

## 个人中心

- **专家中心**（参照 company portal 骨架）：资料编辑、证件上传、项目管理(复用)、留言收件箱(新留言红点)、我的数据(电话被点次数/主页访问量)
- **装企后台**：新增留言收件箱页（读自己 company_id 的询盘）

## 管理后台

- **专家列表**（国家过滤）：审核 / 认证开关 / VIP 开关 / 停用；开关写活动日志（操作人+时间，对账用）
- **装企列表**：加认证开关列
- **数据分析**：电话点击报表（趋势 + 被点排行，按国家/按装企或专家）

## 分期

1. **第一期**：装企认证开关+徽章；电话点击显隐+计数（装企）；admin 点击报表
2. **第二期**：专家体系核心（注册/expert_profiles/个人中心资料证件/简历式主页/找专家列表/后台专家列表+认证开关）+ 导航双入口改造（含空间类型后台化）
3. **第三期**：项目作品接入 + 双端留言收件箱

每期：country-walkthrough 加用例 → 全绿 → 部署。

## 安全/隔离要点

- 电话点击显隐的前提：**详情接口不再返回完整电话**（否则爬虫绕过），完整号码只从 reveal 接口返回
- phone_reveals.country 写入时从目标实体解析（不信任前端）
- expert_profiles.country 注册手机号前缀；admin 专家接口必须 country 过滤；跨表比较注意生产 collation（显式 COLLATE）
