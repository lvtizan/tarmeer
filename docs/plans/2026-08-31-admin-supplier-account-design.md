# 管理员创建免验证供应商账号

## 目标

让具备供应商管理权限的管理员在供应商后台直接创建新账号；该受控路径创建的账号默认通过邮箱验证，供应商可立即使用管理员设置的初始密码登录。

## 方案

在既有 `POST /api/admin/suppliers` 后台接口上创建 `supplier_users` 和 `supplier_profiles`。接口仅允许已登录、具备 `can_view_suppliers` 权限的管理员调用；公开 `POST /api/supplier/auth/register` 保持原有邮箱验证流程不变。

管理员表单包含公司名称、登录邮箱、初始密码和可选联系电话。后端对邮箱、名称、密码和电话号码做校验，使用 bcrypt 哈希密码，写入 `email_verified = 1` 且不生成验证 token；档案归属当前后台选定国家，普通管理员不能指定其他国家。新档案保持 `pending`，仍须走既有审批/上架流程。

## 验收

- 管理员创建账号后，该账号可直接通过供应商登录接口认证。
- 同一邮箱、无效输入、跨国家请求和无供应商权限请求均被拒绝。
- 公开供应商注册仍创建未验证账号。
- 创建结果出现在当前国家的供应商列表，并保留审计记录。
