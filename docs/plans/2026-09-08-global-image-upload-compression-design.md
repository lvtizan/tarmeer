# 全站图片上传自动压缩设计

## 目标

让所有使用 `ImageUploadZone` 的图片入口，在单图选择、粘贴、拖放和文件夹递归拖放时，自动将超过网关限制的单张图片压缩为可上传文件；用户不需要预先处理原图。

## 方案选择

1. 仅提高 Nginx 限制：不能降低 70–90MB 原图带来的网络耗时和服务端内存压力，且仍会遇到更大文件。
2. 服务端压缩：文件必须先穿过网关，不会解决 413。
3. **浏览器端逐张预压缩（采用）**：在公共组件上传前处理，覆盖全部入口，且每张文件单独达标后再上传。

## 设计

- 新增纯前端图片预处理模块，保留非图片和低于阈值的文件原样上传。
- 对超限图片使用浏览器 Canvas 编码：先按最大边缩放，再逐步降低质量与尺寸，直到低于安全目标值；有透明通道时使用 WebP，普通图片使用 JPEG。
- 若浏览器无法解码图片，显示明确错误且不发送肯定会被 413 拒绝的原文件。
- `ImageUploadZone` 在所有入口共用该模块；目录的 PDF 分块上传不受影响。
- 加入单元测试，覆盖压缩阈值、输出格式和渐进压缩策略；构建与供应商上传冒烟用例用于回归。
