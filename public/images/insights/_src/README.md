# Insights 配图 — 给生图 agent（Codex）的清单

把生成的**源图**（PNG/JPG，横图，≥1536px 宽）放进**这个目录**（`public/images/insights/_src/`），文件名必须完全按下表，然后在仓库根目录运行：

```bash
node scripts/build-insights-images.mjs
```

它会自动把每张源图转成站点用的 4 档 WebP（`-blur / -thumb / -medium / 全尺寸`）输出到上级 `public/images/insights/`，覆盖旧图。之后由部署方 rsync 到线上。

## 需要的图（文件名 = 表内 base + `.png`）

| 源图文件名 | 用途 | 画什么（写实、暖色、迪拜情境）|
|-----------|------|------|
| `cost-cover.png` | 装修成本指南 · 封面 | 室内设计师和一对迪拜业主夫妇，在明亮的现代迪拜公寓里围着桌子看装修图纸和材料样板，落地窗外有城市天际线，自然光，生活化写实人像，建筑摄影感 |
| `cost-scene.png` | 装修成本指南 · 正文 | 迪拜公寓装修施工/收尾现场：设计师与施工/木作工人在安装饰面与定制柜，暖色日光，纪实写实人像 |
| `sourcing-cover.png` | 建材采购指南 · 封面 | 迪拜建材仓库/提货场景：本地人(白袍 kandura)与物流/供应商人员看平板核对订单，背景有货车、码放的建材(瓷砖/洁具/箱子)与迪拜天际线，暖色黄昏光，写实纪实 |

## 规格
- 横图（约 3:2 或 16:9），越清晰越好（建议 ≥1536×1024）。
- 风格：**写实照片感 + 真实人物 + 迪拜情境 + 暖色电影感**。
- 尺寸/比例不必精确，脚本会自动裁生成各档。

## 诚信底线（务必遵守）
- 图里的人是**通用示意人物**（像图库配图），**不得冒充某个具体真实客户或真实专家**，不加真实姓名。
- 只做场景示意，不做证件照式"某某本人"。
